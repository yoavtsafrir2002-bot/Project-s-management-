# מערכת ניהול פרויקטים ויומני עבודה — הפיכה לאפליקציה מ-GitHub

הקבצים בתיקייה הזו הופכים את מערכת ניהול הפרויקטים/יומני העבודה לאפליקציה שאפשר להתקין על הטלפון (PWA), מתארחת בחינם ב-GitHub Pages.

**שים לב:** זו אפליקציה **נפרדת** מ"יומן המשימות" הפשוט — מדובר בשתי אפליקציות שונות. מומלץ להעלות כל אחת לריפו נפרד משלה ב-GitHub (למשל `project-journal` ו-`task-journal`), כדי שלא יתערבבו הקבצים (לשתיהן יש `index.html`, `manifest.json` ו-`sw.js` בשם זהה).

## מה יש בתיקייה
- `index.html` — האפליקציה עצמה (ניהול פרויקטים, יומני עבודה יומיים, קבלנים, חתימות, דוחות PDF)
- `manifest.json` — מגדיר שם, אייקון וצבעים לאפליקציה המותקנת
- `sw.js` — Service Worker שמאפשר פתיחה מהירה ועבודה גם בלי אינטרנט
- `icons/` — אייקוני האפליקציה

**חשוב:** כל הקבצים/תיקיות חייבים להיות **באותה תיקייה** בריפו, אחרת הקישורים ביניהם לא יימצאו.

## שלב 1: יצירת ריפו ב-GitHub
1. היכנס ל-github.com.
2. **New repository** → תן שם, למשל `project-journal`. Public או Private — שניהם עובדים.
3. **Create repository**.

## שלב 2: העלאת הקבצים
1. בריפו החדש: **Add file → Upload files**.
2. גרור את `index.html`, `manifest.json`, `sw.js`, ואת **כל תיקיית** `icons` (עם קבצי ה-PNG שבתוכה).
3. גלול למטה → **Commit changes**.

## שלב 3: הפעלת GitHub Pages
1. **Settings → Pages**.
2. תחת **Branch** בחר `main`, תיקייה `/ (root)` → **Save**.
3. חכה דקה-שתיים. הכתובת תהיה:
   `https://<שם-המשתמש-שלך>.github.io/project-journal/`

## שלב 4: התקנה על הטלפון

### אנדרואיד (Chrome)
פתח את הקישור ב-Chrome → תפריט ⋮ → **התקן אפליקציה** / **הוסף למסך הבית**.

### iPhone (Safari)
פתח את הקישור ב-Safari → כפתור השיתוף → **הוסף למסך הבית**.

## עדכון האפליקציה בעתיד
1. העלה קובץ `index.html` מעודכן דרך **Add file → Upload files** (דורס את הישן).
2. שנה ב-`sw.js` את `const CACHE_NAME = 'project-journal-v1';` לגרסה חדשה (`v2` וכו') — אחרת מכשירים שהתקינו את האפליקציה ימשיכו להציג גרסה ישנה מהמטמון.
3. Commit — תוך דקה-שתיים העדכון חי בכתובת.

## גיבוי ושחזור נתונים
בניגוד ליומן המשימות הפשוט, למערכת הזו **יש כבר כלי גיבוי מובנה בתוך האפליקציה עצמה** (מסך הבית → "גיבוי מערכת" / "שחזור מגיבוי"). מומלץ מאוד:
- לבצע **גיבוי מערכת** באופן קבוע (מוריד קובץ JSON עם כל הנתונים) ולשמור אותו במקום בטוח (Drive/מייל לעצמך).
- כשעוברים מכשיר, או מתקינים את האפליקציה מחדש מ-GitHub Pages — להיכנס ל"שחזור מגיבוי" ולטעון את קובץ הגיבוי האחרון.

כל הנתונים (פרויקטים, יומנים, תמונות) נשמרים **במכשיר בלבד** (localStorage) — לא ב-GitHub ולא בענן. GitHub רק מארח את קוד האפליקציה עצמה.

## בעיות נפוצות
- **האפליקציה לא נטענת אחרי Pages** — חכה 2–3 דקות ורענן.
- **האייקון לא מופיע נכון** — ודא שתיקיית `icons` הועלתה במלואה בנתיב הנכון.
- **שינויים לא נכנסים למכשיר שהתקין את האפליקציה** — עדכן את `CACHE_NAME` ב-`sw.js` כמתואר למעלה.
- **הדפסה / שיתוף WhatsApp-מייל לא עובדים** — ודא שאתה פותח את האפליקציה מהקישור של GitHub Pages ישירות בדפדפן (Chrome/Safari), לא דרך תצוגה מקדימה בתוך אפליקציה אחרת.
